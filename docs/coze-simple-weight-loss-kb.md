# Coze 简单版减肥产品客服知识库

整理日期：2026-06-20  
用途：Coze 工作流查询知识库后，直接生成明确回答  
使用方式：每个条目按“用户问题/标准回答/继续追问/转人工/禁止”组织，方便检索命中

## 全局回复规则

1. 用户问什么，先回答什么，不要一上来索要全部信息。
2. 每次最多追问 3 个问题。
3. 不承诺固定减重斤数、固定周期、百分百有效、无副作用、不反弹。
4. 不做医疗诊断，不说产品能治疗疾病。
5. 涉及孕期、哺乳期、未成年、基础疾病、正在用药、付款、退款、投诉、身体不适，必须转人工。
