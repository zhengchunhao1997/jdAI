# 即答 AI 客服后台 UI 设计元信息

## 1. 产品定位

产品名称：即答 AI 客服

当前客户案例：小蓝帽减肥产品 AI 客服

产品类型：AI 客服演示窗口 + 客户运营后台

核心价值：

通过 AI 自动接待用户、识别意向等级、沉淀客户线索、发现知识库未命中问题，帮助商家提升转化、减少人工客服压力，并持续优化销售话术和知识库内容。

## 2. 用户角色

### 商家老板 / 运营负责人

关注：

- 今天 AI 接待了多少人
- 筛出了多少有效线索
- 哪些客户值得马上跟进
- AI 是否真的帮业务节省了人工时间

### 销售 / 私域客服

关注：

- 高意向客户
- 风险客户
- 最近问题
- 下一步跟进动作
- 是否需要人工承接

### 即答交付人员

关注：

- 知识库未命中问题
- 用户真实高频问题
- AI 回复效果
- 后台数据是否持续同步
- 客户业务话术是否需要优化

## 3. 信息架构

```text
登录页
  ↓
后台控制台
  ├─ 今日客服效果总览
  ├─ 线索转化漏斗
  ├─ 高意向客户列表
  ├─ 客户主要问题和顾虑统计
  ├─ 沟通记录
  ├─ 客户线索
  ├─ 待跟进客户
  ├─ 知识库未命中问题
  ├─ 知识库管理
  └─ 系统设置

小蓝帽 AI 客服体验页
  ├─ 聊天窗口
  ├─ 快捷提问
  ├─ 用户输入框
  └─ 桌面端演示信息侧栏
```

## 4. 页面一：登录页

页面目标：

进入后台前的轻量身份验证。

布局结构：

- 居中登录卡片
- Logo：即答 AI客服
- 标题：登录控制台
- 输入项：账号、密码
- 主按钮：登录
- 辅助提示：演示账号 / 客户后台入口

视觉风格：

- 简洁、可信、偏 SaaS 工具感
- 背景浅灰
- 卡片白底
- 主色使用品牌绿或靛蓝
- 不要过度营销化

## 5. 页面二：后台控制台首页

页面目标：

让客户一眼看到“AI 今天干了多少活”。

首屏模块：今日客服效果总览

核心指标卡片：

```text
今日接待人数
今日消息数
AI 自动回复数
人工接管数
有效线索数
高意向线索数
已下单 / 待付款人数
知识库未命中问题数
节省客服时间
AI 解决率
```

设计要求：

- 指标卡片不要太大，适合老板快速扫读
- 数字突出，说明文字弱化
- 高意向、风险、未命中用颜色区分
- 移动端 2 列卡片
- 桌面端 4 列或 5 列

## 6. 页面三：线索转化漏斗

页面目标：

展示用户从咨询到成交的转化路径。

漏斗结构：

```text
咨询人数
↓
提供身高 / 体重 / 目标人数
↓
问价格 / 套餐人数
↓
推荐套餐人数
↓
转人工下单人数
↓
成交人数
```

每一层展示：

- 人数
- 占总咨询比例
- 相比上一层转化率

设计建议：

- 可以做横向漏斗，也可以做纵向步骤条
- 每一步有进度条
- 掉点明显的步骤需要视觉突出
- 重点帮助客户判断转化问题出在哪一环

## 7. 页面四：意向客户列表

页面目标：

告诉销售“今天该跟谁”。

意向等级定义：

```text
A = 高意向用户
B = 中意向用户
C = 低意向用户
D = 风险用户
```

字段：

```text
客户昵称
意向等级
最近问题
身高 / 体重 / 目标
主要顾虑
推荐套餐
下一步动作
最后沟通时间
跟进建议
```

筛选项：

```text
A 级客户
B 级客户
C 级客户
D 级风险客户
问过价格
问过买几套
说考虑一下
已转人工下单
超过 24 小时未跟进
```

视觉要求：

- A 用主色强调
- B 用蓝色或中性强调
- C 用灰色
- D 用红色 / 警示色
- 列表要像 CRM，不要像普通展示表格
- 每一行都应该能快速判断是否值得跟进

## 8. 页面五：客户主要问题和顾虑统计

页面目标：

帮助客户优化客服话术、短视频、小红书内容。

排行榜分类：

```text
价格
效果
安全
用法
反弹
正品
发货
下单
```

每项展示：

- 出现次数
- 占比进度条
- 高频原话示例

示例原话：

```text
多少钱？
多久能瘦？
会不会反弹？
哺乳期能不能用？
买几套合适？
```

设计建议：

- 左侧为分类排行榜
- 右侧为高频原话列表
- 可点击查看原始会话
- 这个模块要让客户感受到“用户到底在关心什么”

## 9. 页面六：沟通记录

页面目标：

查看 AI 和用户的真实对话记录。

字段：

```text
访客
客户问题
AI 回复摘要
意向等级
状态
来源渠道
更新时间
操作
```

状态：

```text
AI 接待中
待人工接管
人工接待中
已关闭
```

交互：

- 点击一条记录，右侧打开会话详情
- 会话详情展示客户画像、AI 分析、建议动作
- 支持按意向等级、状态、关键词筛选

## 10. 页面七：客户画像与 AI 分析侧栏

展示内容：

```text
访客 ID
来源渠道
意向等级
当前状态
关注点标签
会话摘要
AI 建议动作
分配跟进按钮
```

设计要求：

- 右侧固定面板
- 不要做成弹窗
- 适合销售边看边跟进
- 信息密度要高，但层级要清晰

## 11. 页面八：知识库未命中问题

页面目标：

体现系统可以持续优化。

字段：

```text
客户问题
AI 回复
未命中原因
出现次数
状态
创建时间
操作
```

状态：

```text
待补充
已补知识库
已忽略
敏感问题
```

操作：

```text
补充到知识库
忽略
标记敏感
```

设计建议：

- 待补充问题优先突出
- “补充到知识库”是主要按钮
- 这是即答产品价值的重要模块
- 要让客户感受到“系统不是一次性交付，而是越用越懂业务”

## 12. 页面九：知识库管理

页面目标：

维护 AI 可回答内容。

字段：

```text
标题
分类
问题
标准答案
启用状态
命中次数
更新时间
```

操作：

```text
新增知识
编辑
启用 / 停用
```

设计建议：

- 左侧列表，右侧编辑
- 或表格 + 抽屉编辑
- 命中次数用于证明知识库价值
- 编辑区要适合长文本答案

## 13. 页面十：小蓝帽 AI 客服体验页

页面目标：

给客户演示真实 AI 客服能力。

核心结构：

```text
顶部栏
  小蓝帽 AI 体重管理顾问
  在线状态
  返回即答官网
  小蓝帽控制台

聊天区
  AI 欢迎语
  快捷问题
  用户消息
  AI 回复
  输入框
```

默认欢迎语：

```text
你好，我是小蓝帽 AI 体重管理顾问。你可以直接说身高、体重和目标体重，我会先判断适合怎么咨询；也可以问价格、效果、安全和反弹问题。
```

快捷问题：

```text
165，160斤，想瘦到120
什么价格？
会不会反弹？
```

桌面侧栏：

```text
演示信息
产品：小蓝帽
昵称
用户 ID
会话状态

可演示能力：
- 收集身高、体重、目标
- 回答价格、效果、安全顾虑
- 识别高意向并引导人工承接
```

移动端要求：

- 类微信聊天界面
- 顶部尽量短
- 输入框固定底部
- 消息区自动滚动
- 快捷问题随聊天内容向上滚动
- 不展示桌面侧栏

## 14. 整体设计风格

整体感觉：

专业、清爽、可信、偏运营后台，不要像营销落地页。

关键词：

```text
SaaS
CRM
AI 客服
销售线索
运营看板
客户跟进
知识库优化
```

不要使用：

```text
大面积渐变
过多装饰插画
营销型 hero
过度圆角
大卡片堆叠
花哨动画
```

推荐视觉：

```text
背景：#F8FAFC / #F9FAFB
主色：#10B981 或 #4F46E5
标题文字：#111827
正文文字：#4B5563
弱文字：#6B7280
边框：#E5E7EB
危险 / 风险：#EF4444
警告：#F59E0B
成功：#10B981
```

## 16. 响应式要求

### 桌面端

- 左侧导航 + 顶部栏 + 主内容区
- 表格可横向滚动
- 会话详情可右侧固定
- 指标区 4 到 5 列

### 平板端

- 侧边栏可折叠
- 指标 2 到 3 列
- 表格保留横向滚动
- 详情面板可下移或抽屉化

### 移动端

- 侧边栏变抽屉
- 指标 2 列
- 表格改卡片列表
- 聊天页全屏优先
- 聊天页不展示侧栏

## 17. 核心体验目标

用户打开后台后，3 秒内应该明白：

```text
今天 AI 接待了多少人
筛出了多少高意向客户
哪些人需要马上跟进
用户最关心什么问题
知识库哪里需要补
```

这套 UI 不只是展示数据，而是要让客户感觉：

AI 客服每天都在帮我接待、筛选、总结、提醒跟进。
