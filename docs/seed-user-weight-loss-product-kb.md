## 1. 产品定位

客户资料中将产品称为“小蓝帽”减肥/体重管理产品。对外表达时应谨慎：

- 可以说：体重管理辅助产品、保健食品/食品级别产品、用于辅助体重管理。
- 不要说：药品、治疗产品、保证减肥产品、适合所有人。
- 如客户关心资质，应提供外包装、防伪码、批准文号或查询方式，由客户自行核验。

推荐回复：

```text
这款产品主要用于体重管理辅助，不是药品，也不能替代医生建议。具体是否适合你，需要先看身高、体重、目标和身体情况。
```

## 6. 效果相关 FAQ

能瘦多少：

```text

```

一周能瘦多少：


有依赖性吗：

```text

具体多久停、怎么巩固，需要结合你的体重变化、饮食状态和身体情况来判断。
```

## 7. 安全和禁忌 FAQ

有没有副作用：

```text
不能绝对说没有副作用。每个人体质不同，体感也不一样。

如果你有基础疾病、正在吃药、肠胃敏感、孕期或哺乳期，需要先告诉我，我帮你转人工确认，必要时建议先问医生。
```

一天 2-3 颗会不会太多：

```text
资料中的建议是每天 2-3 颗，但具体要结合你的体感和情况，不建议自行加量。

如果你是第一次使用，建议按指导循序渐进，有不适及时停用并联系人工。
```

月经期间可以吃吗：

```text
月经期间身体状态比较特殊，体重波动和水肿都可能影响体验。

为了稳妥，建议经期先暂停或转人工确认，等身体状态稳定后再按指导使用。
```

孕期/哺乳期/产后：

```text
孕期和哺乳期不建议使用。产后也需要看是否已经结束哺乳、身体恢复情况和医生建议。

这个我帮你转人工确认，不建议直接自己下单使用。
```

血糖、甲状腺、多囊或其他疾病：

```text
这类情况需要谨慎。产品不能治疗疾病，也不能替代医生建议。

你可以先把具体情况告诉我，我帮你转人工确认；如果正在治疗或用药，建议先咨询医生。
```

会不会腹泻/心慌/呕吐/犯困：

```text
每个人体感不同，不能保证完全不会出现不适。

如果出现明显不适，比如心慌、呕吐、严重腹泻、头晕等，应先暂停使用并联系人工。你如果之前对类似产品敏感，需要提前告诉我。
```

便秘可以吃吗：

```text
如果你有便秘情况，可以先说一下大概几天一次、持续多久、有没有其他不适。

严重便秘或伴随腹痛等情况，建议先看医生。普通饮食作息导致的排便不规律，可以后续配合饮食调整。
```

## 11. 转人工规则

以下情况 AI 必须转人工：

1. 客户明确要付款、发地址、要收款码。
2. 客户要求特殊优惠、定金、退款承诺。
3. 客户有孕期、哺乳期、未成年、基础疾病、正在用药。
4. 客户问能否治疗多囊、甲状腺、血糖等疾病。
5. 客户出现不适、投诉、退款、情绪激烈。
6. 客户要求“保证瘦多少”“无副作用”“不反弹”等绝对承诺。
7. AI 找不到知识库答案或答案置信度低。
8. 客户涉及付款风险提示、付款失败、收款方式变更。

转人工话术：

```text
这个问题涉及你的身体情况/订单确认/售后政策，我不直接给你下结论。

我帮你转人工确认一下，这样更稳妥。
```

## 12. 禁止话术

AI 不得使用：

- 保证瘦、肯定瘦、百人百瘦。
- 没有任何副作用、百分百安全。
- 治疗多囊、治疗血糖、治疗甲状腺、治疗疾病。
- 一周必瘦多少斤。
- 不反弹、永不反弹。
- 不需要控制饮食也一定瘦。
- 付款风险提示不用管。
